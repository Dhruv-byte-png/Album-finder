
# 🎵 Album Finder

A JavaScript-based web application that uses the **Spotify Web API** to search for albums and display their information in a clean, interactive interface.

## 🚀 About the Project

Album Finder is a practice project built to learn how to work with **JavaScript, APIs, asynchronous programming, authentication, and DOM manipulation**.

Users will be able to search for albums and view information such as:

* 🎵 Album name
* 👤 Artist
* 🖼️ Album artwork
* 📅 Release date
* 🔗 Spotify album link

## ⚙️ Setup

1. Clone this repository.
2. Create a Spotify Developer application.
3. Add the required redirect URI.
4. Configure the Spotify Client ID locally.
5. Open the project using a local development server.
6. Run the application in your browser.

> **Note:** Never commit your Spotify Client Secret, access tokens, or other sensitive credentials to GitHub.

## 🎯 Project Goal

The main goal of this project is to understand how a frontend JavaScript application communicates with an external API and turns the returned data into an interactive user interface.
